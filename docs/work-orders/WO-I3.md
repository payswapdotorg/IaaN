# WO-I3 — Vertical Scenario Packs

**Owner:** Tech lead + assigned worker
**Paths:** scenario fixtures, reusable adapters, and scenario tests
**Prerequisites:** WO-I2, WO-C3

Implement reusable end-to-end packs for compute pool, shared vehicle/collective asset, distributed factory, and network provider scenarios.

## Acceptance
Each scenario demonstrates the generic lifecycle plus at least one failure/recovery path. No scenario adds vertical-specific primitives to the kernel.
